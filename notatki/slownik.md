# Słownik odpowiedników usług chmurowych

| Rodzaj usługi | AWS | Azure | Google Cloud |
|---|---|---|---|
| Maszyny wirtualne (IaaS) | EC2 | Virtual Machines | Compute Engine |
| Platforma aplikacji (PaaS) | Elastic Beanstalk | App Service | App Engine |
| Funkcje bezserwerowe (FaaS) | Lambda | Azure Functions | Cloud Run functions |
| Pamięć obiektowa (Storage) | Simple Storage Service (S3) | Blob Storage | Cloud Storage |
| Relacyjne bazy danych (DBaaS) | Relational Database Service (RDS) | Azure SQL Database | Cloud SQL |
